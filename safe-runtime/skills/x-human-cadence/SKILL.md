# X human cadence

Timezone is Asia/Jakarta. The parent already owns the clock. Keep these
routines as the parent wrote them:

- Scan every 3 hours, and keep candidates at or above 32/40.
- Morning pass at 08:00.
- Evening pass at 19:00.
- Weekly pass on Sunday at 18:00.

07:00 and 12:30 WIB are reported helpful windows for a person who is about to
open a composer. They are heuristics. They are not a growth result, and this
bundle does not install a cron for them.

## Pace, when the operator decides to post

- One original in a given hour is enough.
- Leave gaps. A missed hour stays missed.
- Weekdays and weekends can both carry a post when the operator is actually there.
- A scan can end with no draft. Silence is a valid result.
- Reply in small batches, with a pause between them.

## What this skill does not do

It does not like, follow, bookmark, or DM. It does not run a browser session
on x.com. It does not invent a second schedule on top of the parent routines.
